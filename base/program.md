下面是一些适合练习 Go 基础的编程题，从入门语法到切片、map、结构体、接口和并发都有一点。

1. **判断奇偶数**  
   输入一个整数，判断它是奇数还是偶数。

2. **求 1 到 N 的和**  
   输入一个正整数 `N`，计算 `1 + 2 + ... + N`。

3. **九九乘法表**  
   使用嵌套循环打印九九乘法表。

4. **数组最大值**  
   给定一个整数数组，找出其中的最大值和最小值。

5. **反转字符串**  
   输入一个字符串，输出反转后的字符串。  
   注意考虑中文字符。

6. **统计字符出现次数**  
   输入一个字符串，使用 `map` 统计每个字符出现的次数。

7. **切片去重**  
   给定一个整数切片，返回去重后的切片。

8. **冒泡排序**  
   手写冒泡排序，对整数切片从小到大排序。

9. **斐波那契数列**  
   输入 `N`，输出前 `N` 个斐波那契数。

10. **判断回文字符串**  
    判断一个字符串是否是回文，例如 `level`、`上海自来水来自海上`。

11. **学生成绩管理**  
    定义一个 `Student` 结构体，包含姓名、年龄、成绩。  
    实现：
    - 添加学生
    - 查询某个学生
    - 计算平均分
    - 找出最高分学生

12. **简单计算器**  
    输入两个数字和一个运算符 `+ - * /`，输出计算结果。  
    注意除数为 0 的情况。

13. **统计单词数量**  
    输入一段英文文本，统计每个单词出现的次数。

14. **文件行数统计**  
    读取一个文本文件，统计文件中有多少行。  
    可练习 `os.Open`、`bufio.Scanner`。

15. **复制文件**  
    实现一个简单的文件复制程序，将源文件内容复制到目标文件。

16. **结构体方法练习**  
    定义 `Rectangle` 结构体，包含宽和高。  
    为它实现两个方法：
    - `Area()` 返回面积
    - `Perimeter()` 返回周长

17. **接口练习：图形面积**  
    定义一个 `Shape` 接口，包含 `Area() float64` 方法。  
    实现：
    - 圆形 `Circle`
    - 矩形 `Rectangle`
    - 三角形 `Triangle`

18. **错误处理练习**  
    编写函数 `Divide(a, b float64) (float64, error)`。  
    当 `b == 0` 时返回错误。

19. **goroutine 打印数字**  
    启动两个 goroutine：
    - 一个打印奇数
    - 一个打印偶数  
      尝试让它们交替输出。

20. **channel 求和**  
    将一个整数切片分成两半，分别用两个 goroutine 求和，再通过 channel 汇总结果。
